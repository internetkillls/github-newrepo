# Coursecraft Lab v0.2

A skills-only private course designer and tutor: visual-first, source-grounded, learner-evidence-driven, with anti-slop explanations and critical diagram translation. Adds selective Reasoning Method Controller-style gates for course framing, dependency repair, verification, source-role separation, and curriculum revisions.

Start with `/course TouchDesigner live visual performance from fundamentals`. Use `/anti-slop` on a draft explanation, `/diagram-audit` on a proposed visualization, and `/resume` with a portable Learning Contract. This version does not add a persistent backend, interactive app runtime or real host tool integrations.


## v0.4.0 — Visual learning experience router
Added representation choice, lesson UI/UX contract, accessibility/interaction states, contextual click/recovery specifications, and visual regression witnesses. These are pedagogical design instructions, not a new rendered LMS or a guaranteed runtime. Existing source scout, anti-slop, source-role firewall, and course contracts remain preserved. Method sources include Mayer/Fiorella, CAST UDL 3.0, W3C WCAG 2.2, NN/g, H5P examples, and internal Visual Pipeline methods.
