# Publication benchmark — assess the ARTIFACT and CHANNEL, never human worth

## Minimal intake
Use the user's actual artifact or question, desired audience and channel, verified sources, author ownership and time. If unknown, proceed with `provisional channel: ...` and an exploratory benchmark, not a categorical verdict.

## Universal assessment dimensions (qualitative, witnessed)
A. `authentic authorship / provenance`: user-authored argument, user-made demo, permitted reuse; assistant drafts are not a user's accepted stance.
B. `central contribution`: precisely state what this work adds beyond summarizing the reported story.
C. `support`: methods, citations, runnable demo, original footage, data, permissions, fit to claim.
D. `interpretive rigor`: strongest alternative; novelty claim relative to source set; limits.
E. `reader/user value`: audience, intelligibility, reproduction/explanation, accessibility.
F. `ethics/rights`: consent, privacy, attribution, licensing, relevant AI disclosure, conflicts.
G. `channel fit`: exact submission category, formatting, acceptable length, relevant current policies.
H. `operational readiness`: valid target and route, required files, accounts, receipts.

For each use `evidenced / partly evidenced / unknown / not met / not applicable`. No invented scores, venue prestige weights, percentage chance of acceptance, or numerical success probabilities.

### Channel-specific discriminators
- **Research journal:** research question, state of the debate, novel argumentative or empirical contribution, method fit, citation sufficiency, strongest objection, plagiarism/version/AI declarations, authorship and submission guidelines. A polished news digest typically lacks new research.
- **Scholarly commentary/review/letter:** explicit editorial article type, supported critical angle, substantive interaction with literature, proper peer-review status; do not call a social-media essay peer-reviewed.
- **LinkedIn:** accurate proposition + concrete professional implication + provenance/CTA; outcome can be quality conversation or profile visits rather than raw views.
- **Instagram/TikTok:** distinct designed artifact, first-frame clarity, attribution and use rights, accessibility/captions, claims that survive simplification; visuals cannot transform an unverified scientific claim into fact.
- **Github:** evidence-backed reproducible code/docs/test, scope and maintainability, project contribution policy, issue/PR/review/merge witnesses; public commit graph not sufficient proof of accepted contribution.

## First-time benchmark flow
1. Inspect ONE candidate artifact without assuming the user has already completed it.
2. Find TWO verified realistic comparators in the same medium and level. Cite exact artifact links and note date, journal article category or repo maintainer requirements; if unavailable, label rubric synthetic.
3. Produce `what it already demonstrates`, `what the comparator demonstrates that it doesn't`, and `one cheapest falsifiable improvement`.
4. Run a 10-minute micro-witness: journals → reconstruct central claim + counterargument + two live literature anchors in 200–300 words; visual → make 30-second script and identify one potentially misleading compression; repo → reproduce a bug or propose test and report expected vs actual; LinkedIn → short draft and separate evidence from opinion.
5. Evaluate the output and rerun one test, then choose `publish / submit for review / draft more / switch format / defer` based on evidence and user approval.
6. Capture the result in a portable contract. Only documented attempts count, no pass merely because an AI wrote the answer.

### Benchmark decision table semantics
`not ready for JOURNAL yet` can coexist with `ready for LinkedIn explanatory essay`, because the criteria differ. `procedural blocker` is not `substantive failure`. Submission readiness is not editorial acceptance. High follower count is not rigor. Low follower count is not low quality.
