# Verified assignment bank protocol

Aim: collect the closest REAL instructional exercise, rubric, class project, exam sample, or evaluated submission from an identifiable author or institution. Do not synthesize and attach their institutional reputation to an invented assignment.

Search across official open course sites, institution repositories, publicly published rubrics, verified exhibition/submission examples, GitHub assignments where provenance is clear, and supported access-controlled course platforms if authorized. Use exact qualification level and topic. Prefer public legal reuse.

For every outside exemplar record:
- institution/course/author; title and term/date if available
- direct URL and observed content, not only snippet
- type: assignment prompt / rubric / example submission / solution / tutorial / assessment
- target level and actual prerequisite
- required deliverable format (PDF, PPTX, source code, presentation, etc.)
- constraints, duration, and marking criteria exactly when known
- license/copyright/access and what portion can be reproduced
- verification status: `verified-original`, `secondary`, `unverified`.

If source does not include score/grade or rubric, do NOT imply it has one. An exemplar PPTX is not necessarily a graded assignment. Provide a short paraphrase and link rather than lengthy reproduction. If no authentic matching problem can be retrieved, explicitly label **Course-generated practice (not institutional assignment)**. May propose learner-relevant practice with transparently constructed evaluation rubric, separate from externally authored rubric.

Track assessment matrix per lesson: concept, observable behavior, authentic reference, result, evidence, remediation, transfer challenge. Do not promote student from completion of mirroring alone.
