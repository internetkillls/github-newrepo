# Visual Pipeline
24 skills:19 adapted TD skills +5 independently authored studio workflow skills. Start with studio-visual-pipeline for the confirmed cube brief and pipeline; use td-general for actual TouchDesigner work.
This package carries editable project context, draft spec, an analytic seamless recipe, and an offline validation/plan/cue/catalog helper. It supports source/plan handoffs to TD, Blender and p5.js; arbitrary projects still require recipe-specific adapters and application testing.
Install through a supported Codex local marketplace or save the ZIP privately through Plugin Creator. Existing unrelated plugins/skills are preserved. Reload the client/start a new chat for refreshed skill discovery.
Applications/MCPs are configured separately. The default timezone is intentionally unknown and session boundaries are proposals. The helper never triggers a show player. See ATTRIBUTION.md and LICENSE-TDMCP.md for TD-origin terms.
