# Delivery and cue package
Folders: spec/, source/, assets/, previews/, media/<theme>/<session>/, manifests/, mapping/, checks/. Manifest links project/theme/session/variant IDs, media hashes, duration/fps, logical face order, packing and check records.
Linear master7200x1080 has face x intervals[0,1800),[1800,3600),[3600,5400),[5400,7200). Grid3600x2160 uses explicit tile order, e.g.A top-left,B top-right,C bottom-left,D bottom-right; tile order is unrelated to actual clockwise screen order until calibrated. Both contain7,776,000 pixels. Hardware codec limits and playback costs need testing.
Supply a face-ID/grid calibration still or clip with clearly marked orientation. Configure Arena Advanced Output slices/screens on actual hardware; do not infer from cable count. Continuous media does not prove display scan/frame synchronization.
Encoding: use supported Resolume Alley/other verified encoder to create a tested DXV MOV master from rendered frames when appropriate; H.264 MP4 preview separately. Pick HQ only after an artifact/banding comparison. Keep intended alpha and explicit color transforms. Verify actual output metadata and playback after conversion.
Cues: show evening theme persists after midnight. Proposed offsets0..3600 opening,3600..9000 warming,9000..18000 peak,18000..21600 farewell. At21600 show ends. Timezone and boundary approval are unresolved in the example. Operator may override; future automation must preserve manual override and recover current session after restart instead of replaying the opening.
