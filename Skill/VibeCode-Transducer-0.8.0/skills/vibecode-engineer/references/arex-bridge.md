# Optional VCT v0.5.0 AREX bridge

For AREX/DisCo, cross-repository ML research, repo-capability donor discovery, or authoring/updating verifiable operating skills, use the sibling plugin skill `skills/arex-repository-intelligence/SKILL.md`. Its `runtime/arex_router.py` is an offline read-only catalog adapter. It loads metadata from the bundled 1,000-repository snapshot; it does **not** load DisCo automatically, fetch source, install model packages, run third-party scripts, certify donors or modify target code. Its results are limited to evidence-gated candidates and must feed existing RMC, AntiSlop and VCT validation. For mathematical decisions, still invoke a real Python tool with the relevant observation payload under VCT's original contract; merely ranking AREX metadata is insufficient.
