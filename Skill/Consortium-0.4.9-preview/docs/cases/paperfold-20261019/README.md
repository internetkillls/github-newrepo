## Supported lessons

- Preserve a causal human episode through architecture, state/data contracts, implementation and outcome evaluation.
- A selected design must retain its strongest rival and the evidence that would reverse selection. W4's writer-first judgment had no human A/B validation.
- Require full artifact identity and section coverage before dependency adjudication. W7's corrected reread reconciled W5 motion and complete interaction classes.
- Disjoint files still share an event/DOM API. W8's added Capture dialog did not remove W9's existing direct-write listener.
- Test actual native high-risk states early. Broad fixture matrices missed native dark-control contrast.
- Separate transport/source delivery from runtime/release. W10's hash-valid source transfer coexisted with honest BLOCKED release status.
- Original-worker interviews are I0 AI self-report. Compare them with artifacts; do not call them human feedback or independent verification.

## Candidate regressions, not executed runtime features

| Input / failure | Required expected behavior | Negative control |
|---|---|---|
| Hash-valid source, release BLOCKED | Retain delivered source and native debts; do not reintegrate for a PASS label | Truly corrupt source must fail transport integrity |
| Missing/truncated predecessor document | Hold canonical planning until full length/hash and relevant sections acknowledged | Complete verified document may proceed without repeated delivery |
| Dialog added over existing write listener | Pre-confirm/no-write probe detects bypass and reopens behavior owner | Explicit confirmed commit still writes correctly |
| Worker cites host summary | Label host-supplied; no worker-witness promotion | Directly accessible artifact can be corroborated for its own scope |
| Complete response, interview PARTIAL | Keep transport WITNESSED and evidence PARTIAL separately | Fully accessible answer does not inherit unrelated unknowns |
| Uncertain send | Reconcile exact prompt/turn; never automatic duplicate | Proven pre-send failure may receive bounded recovery |
| Broad fixture PASS, missing native condition | Native claim stays unverified | Real named native receipt can satisfy that precise condition |

These are proposed regression requirements derived from the case, not claims of newly implemented/executed RCC test functions. The release's verification receipt covers document links, preserved configuration, manifests, archives and recorded completion evidence.
