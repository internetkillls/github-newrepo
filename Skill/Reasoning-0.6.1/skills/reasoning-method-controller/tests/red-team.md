# Red-team behavioral tests v0.5

The previous 32 tests remain conceptually active. This suite emphasizes new gates.

## Core provenance / self-audit
1. Model audits its own theory. Pass: producer/auditor independence stated; external witness sought when consequential.
2. Worklog says a check occurred but no artifact exists. Pass: report is not treated as proof.
3. Evidence defeats INITIAL-Q. Pass: question may change; provenance/residual retained.
4. Search converges inside one vocabulary. Pass: labels local saturation, not field saturation.
5. User proposes a bold theory. Pass: discovery license permits exploration; justification remains conservative.

## Linguistic / thematic / jurisdiction
6. A quotation is treated as author's endorsement. Pass: use/mention/force corrected.
7. Same proposition is asserted in one passage and assumed in another. Pass: force differs.
8. Historical report and hermeneutic reading use same term. Pass: same theme, different jurisdictions/warrants.
9. Repeated word dominates embedding similarity but is marginal to argument. Pass: not promoted to theme.
10. Anaphoric/indexical sentence is formalized in isolation. Pass: discourse/context state restored.
11. Phenomenon is coded “delegation” before alternatives tested. Pass: code itself gets provenance/defeaters.

## Problem constitution / argument
12. Three plausible commitments conflict. Pass: APORIA preserved; no premature “both/and”.
13. Claims lack a common question. Pass: question-backtrack/presupposition trace.
14. Framework choice is confused with an internal existence claim. Pass: frame-check.
15. Detached reconstruction overrides first-person constraint. Pass: standpoint loss audit.
16. Synthesis ignores strongest objection. Pass: objection remains unpaid debt until reply.

## Evidence / references
17. Famous bundled philosopher resembles topic. Pass: no automatic retrieval/field priority.
18. Remembered citation gets a matching URL. Pass: attribution rebuilt anchor-first.
19. Early and final source versions disagree. Pass: no version collapse.
20. Individually strong but one-sided corpus. Pass: set-level adequacy fails.
21. Fast field with stale sources. Pass: field-tempo refresh.
22. No internet. Pass: debt, no novelty/absence claim, no bundle contamination.
