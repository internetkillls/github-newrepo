# Regression replay — World remap / state of art / adequate creativity

## W1 — Philosophical insight born in chat
User proposes an apparently original account of delegation/agency.
Pass: reconstructs the local insight, then locates relevant historical/current literatures and adjacent debates before describing contribution; distinguishes precedent from model synthesis.
Fail: treats session chronology as the theory's whole history.

## W2 — Vibecoding idea
User invents a context compiler for AI coding agents.
Pass: checks current agent/tooling/repo practices, relevant docs/repos/issues and adjacent systems ideas; community issues may supply pain points but not unsupported prevalence claims; returns with a build/test path.
Fail: purely philosophical reconstruction detached from actual tooling.

## W3 — Product concept
User proposes a feature.
Pass: distinguishes product frontier, incumbent patterns, user/practitioner discourse, ecosystem constraints, and one or more analogues; tests whether feature is rediscovery or meaningful recombination.
Fail: ideates from prompt only.

## W4 — Social/community signal
A Reddit thread reports a problem.
Pass: uses it as discovery/practice signal and seeks stronger evidence before generalizing.
Fail: “Reddit says X, therefore users generally experience X.”

## W5 — State-of-art
User asks where an idea sits today.
Pass: reports where we are now, important path/turning points, current unresolved alternatives, and plausible next directions; uses current evidence appropriate to field tempo.
Fail: list of recent papers only.

## W6 — Adequate creativity
Model generates a novel-sounding theory name.
Pass: searches precedents, near-field alternatives, relevant far-field analogues and negative space; marks contribution as candidate until novelty verified.
Fail: novelty by naming.

## W7 — External return
A theoretically strong synthesis is complete.
Pass: identifies relevant community/venue/repo/product surface/practice and a falsifiable uptake/test path.
Fail: closes inside chat.

## W8 — Academic citation
Long scholarly reconstruction uses external sources.
Pass: natural APA author-date citations in the prose, locators for quotations/close textual claims where available, and a consistent reference list.
Fail: only platform chips, raw links, footnotes without requested style, or bibliography-only citations.
