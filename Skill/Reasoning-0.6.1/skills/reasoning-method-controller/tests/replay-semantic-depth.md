# Regression replay — semantic depth / conceptual descent v0.5.5

## S1 — Justice is not a synonym cloud
Prompt contains "justice" in a theory-building context.
Pass: identifies the governing problem and relevant framework(s), then unpacks constitutive/institutional/inferential structure; if Rawls is relevant, explains why rather than treating "fairness" as sufficient.
Fail: justice → fairness → equality → rights → morality with no dependency structure.

## S2 — Framework plurality
"Justice" appears without enough context to choose Rawls, Nozick, recognition, capability, contractarian, etc.
Pass: preserves multiple materially different candidate frameworks or minimally branches.
Fail: first famous framework becomes the universal meaning.

## S3 — Collingwood backtrack
A proposition seems clear but its role depends on an unspoken question.
Pass: recovers the question/presupposition and shows how it changes the proposition's function.
Fail: treats sentence meaning as context-free lexical content.

## S4 — Verbal dispute residual
Two parties use the same term differently.
Pass: brackets/eliminates the word, states residual substantive commitments, then reconstructs each sense if needed.
Fail: concludes "just semantics" merely because definitions differ.

## S5 — Argument scheme depth
A normative claim uses a compressed concept as warrant.
Pass: exposes the hidden premise/warrant and critical questions; does not just define the keyword.
Fail: dictionary-style definition replaces argument reconstruction.

## S6 — Strawson mode distinction
Model reconstructs an existing conceptual scheme and then proposes a better one.
Pass: distinguishes descriptive reconstruction from revision.
Fail: revision is laundered as description.

## S7 — Material/practical realization
A social/institutional concept matters to the conclusion.
Pass: identifies relevant actors, practices, procedures, powers, or institutional conditions from object evidence.
Fail: stays at abstract semantic neighborhood only.

## S8 — Technical concept
"State" in a software architecture discussion.
Pass: if inference-bearing, unpacks relevant persistence/ownership/lifecycle/concurrency semantics from the actual system.
Fail: offers generic dictionary synonyms or metaphysical digression.

## S9 — No overdescent
User asks a simple lexical translation.
Pass: answer remains simple.
Fail: semantic-depth machinery turns every word into a metaphysical genealogy.

## S10 — Policy-content firewall
The semantic-depth module contains justice/Rawls as an example.
Pass: unrelated answers do not introduce Rawls or justice unless object-relevant.
Fail: controller example becomes recurring answer content.

## S11 — Inferential commitment
A term's meaning changes what follows in the argument.
Pass: states which inference is licensed under sense A but not sense B.
Fail: sense distinction is merely terminological with no consequence.

## S12 — Descent before formalization
A term is about to become a variable.
Pass: establish what relation/condition the term denotes before symbol assignment.
Fail: word → variable directly.

## S13 — Natural prose
Long-form explanation uses semantic descent internally.
Pass: output reads as patient conceptual prose, not a ledger headed QUESTION / PRESUPPOSITION / MATERIAL REALIZATION / etc.
Fail: internal descent schema leaks into final output.
