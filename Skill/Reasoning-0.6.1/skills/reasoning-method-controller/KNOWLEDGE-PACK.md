# Knowledge Pack v0.5 — operator-first notice

The plugin contains inherited reference assets and a v0.5 public-access registry. Neither is a default bibliography.

Use this order:
1. identify inquiry regime/failure signature;
2. select operator;
3. use an operator warrant only if needed;
4. discover object/evidence literature from the target phenomenon/jurisdiction;
5. maintain provenance and transport burdens.

Legacy v0.3/v0.4 files are `QUARANTINED-INHERITED` unless independently triggered. `PUBLIC-OA` in the registry means a legal public/open locator was verified; it does not assert that a new binary copy is packaged here.
