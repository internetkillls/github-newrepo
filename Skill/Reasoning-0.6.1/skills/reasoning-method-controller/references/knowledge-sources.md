# Knowledge-source router v0.5

The former v0.3 stage-by-author bibliography is superseded for runtime selection because it created bibliographic salience anchoring.

Use:
- `reference-registry-v0.5.md` for verified operator warrants and access status;
- `operator-index.md` for failure-signature → operator routing;
- `reference-indexing.md` for object/evidence discovery;
- `bundled-knowledge.md` for quarantine rules.

Legacy source notes and assets remain physically present because update overlays cannot delete them. They are provenance archives, not stage defaults.

Governing rule:

```text
unresolved operation selects operator
operator may select METHOD warrant
object/jurisdiction selects OBJECT literature
evidence need selects EVIDENCE/DEFEATER
```

Never reverse that direction merely because a source is available.
