## Operational reference activation

`SOURCE → claim/method warrant → ST rule → entry condition → skill step → paired case → outcome receipt`.

- BUNDLED: the RMC original package bundles Chalmers and Walton PDFs; this update does not duplicate copyrighted PDFs.
- REFERENCED: sources listed here with persistent publisher/repository links.
- LOADED: citation/repository pages inspected during this upgrade; full RMC original PDFs not reanalyzed in this run.
- APPLIED: the stated distinction shaped rule admission, negative control or transfer limit.
- TESTED: local **fixture validator only**; actual model transcript evaluation remains unperformed unless separately recorded.
- VERIFIED: only source identity, repository contents, schema and physical package status appropriate to direct access; **not** semantic model improvement.

No source author is attributed the controller's own synthesized rule. The source is an evidence position, not a prediction about GPT-6's internals.
