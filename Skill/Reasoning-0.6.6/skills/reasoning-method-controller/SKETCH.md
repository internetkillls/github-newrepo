# Method sketch v0.6.0

```text
REQUEST / ARTIFACT
      ↓
S0 INTAKE
object · goal · hard constraints · provenance · high-leverage ambiguity
      ↓
S1 ROUTE FAMILY
reconstruct | research | design/debug | compare | formalize | theory | mixed
      ↓
S2 FRAME
question · claim type · criterion · jurisdiction
      ↓
S3 DECOMPOSE
terms · premises · dependencies · mechanisms · source roles · unknowns
      ↓
S4 OPERATE
failure signature → smallest licensed operator
      ↓
S5 TEST
rival · counterexample · probe · falsifier · boundary/second-order effect
      ↓
S6 EVIDENCE / WORLD   [only if unresolved function requires it]
source adequacy · version · external placement · negative evidence
      ↓
S7 INTEGRATE
provenance · transport · contradiction · return to original problem
      ↓
S8 CLOSURE
candidate stability + evidence topology + what would change this
      ↓
S9 DELIVER
natural requested genre

Any failed dependency → repair the earliest failed stage.
Any stage whose exit condition is already satisfied → skip it.
```

The operator index is a subrouter inside the stage machine, not the global workflow. The sketch is internal control topology, not an output template.
