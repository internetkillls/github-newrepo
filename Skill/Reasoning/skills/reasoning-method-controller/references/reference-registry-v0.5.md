# v0.5 operator-warrant and public-access registry

Checked for this v0.5 update on 2026-10-06. This is a **router**, not a default bibliography. A registry entry does not support a task-specific claim until the relevant passage/artifact is inspected. `PUBLIC-OA` means stable open/public text is available; it does not mean this release physically rebundles the file.

## Problem constitution, question/presupposition, aporia

### John Dewey — *How We Think*
- Access: `PUBLIC-OA` / public domain in the USA via Project Gutenberg.
- Warrant: reflective inquiry begins from difficulty/perplexity and develops a problem rather than treating the first wording as final.
- Forbidden promotion: Dewey does not make every task an educational or pragmatist theory.
- Locator: https://www.gutenberg.org/ebooks/37423

### R. G. Collingwood — logic of question and answer / presuppositions
- Access: `PUBLIC-ACCESS` exposition; primary book copyright status varies.
- Warrant: distinguish propositions that answer questions from presuppositions that give rise to questions; backtrack answers to governing questions/presuppositions.
- Forbidden promotion: do not treat every unstated premise as an “absolute presupposition”.
- Locator: https://plato.stanford.edu/entries/collingwood/

### Nicholas Rescher — “Aporetic Method in Philosophy” (1987); *Aporetics* (2009)
- Access: `PUBLIC-ACCESS` metadata/abstract; full text restricted.
- Warrant: preserve individually plausible but collectively incompatible theses as an aporetic cluster before revision.
- Forbidden promotion: inconsistency alone does not identify which thesis to reject.
- Locators: https://philpapers.org/rec/RESAMI ; https://philpapers.org/rec/RESARD

## Representation, measurement, and formalization

### Patrick Suppes & Joseph L. Zinnes — “Basic Measurement Theory” (1963)
- Access: `PUBLIC-OA` author/institutional corpus PDF; reproduction note appears in the hosted chapter.
