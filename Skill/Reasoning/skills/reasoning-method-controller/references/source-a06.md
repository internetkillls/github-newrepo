## Source-oriented reading note

The plans/situated-actions discussion treats activity through its unfolding relation to circumstances; ordering devices support action without fully fixing every contingency.

## Controller adaptation (model-authored)

Trigger: Investigate differences between a plan and enacted activity.

Operation: Compare planned steps with observed use and context; revise a plan when evidence changes a requirement or mechanism.

Boundary: Plans are not useless, all deviations are not errors, and interface structure alone is not evidence of actual use.

The source-oriented note is a paraphrase of selected inspected passages; the controller adaptation is an implementation proposal, not the author’s own instruction for AI. Read the passage and surrounding context before attribution. Physical PDF page numbers and printed page numbers are distinct.
