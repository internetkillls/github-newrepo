# Ideation and personal design cues

Separate venue identity from the daily theme and from the session's energy. Derive concepts from provided references and rights-cleared assets; Bali is context, not permission to invent cultural symbols or assume a tropical aesthetic.

Read [references/cue-card.md](references/cue-card.md). Preserve preference provenance: user statement, approved example, or hypothesis. Ask a focused preference question only if alternatives materially change the pilot; progress on the brief and feasibility meanwhile.

Produce up to three genuinely distinct concept cards: one-sentence intent, shape language, palette, motion, density, light/dark balance, four-face continuity, session modulation, required assets and approximate technical risk. Compare them against the same criteria. Mark any selected default as proposed until approved.

Choose one shared recipe with bounded parameter variation, rather than unrelated prompts for every screen. Keep coordinate/clock invariants across opening, warming, peak and farewell. Represent daily theme as a palette/recipe/asset revision; preserve the previous show-day theme across midnight until show end.

Return a reusable concept card and a spec delta. Do not claim mockups or clips exist unless produced. Preserve decisions in the project catalog and link source references.
