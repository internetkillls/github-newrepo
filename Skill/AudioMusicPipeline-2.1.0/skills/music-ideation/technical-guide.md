# Technical Guide: Music Ideation

## Bounded Variation Matrices
When ideating variations for a musical motif:
- **Pitch Inversion**: Reflect note intervals across the tonal center axis ($y' = 2 \cdot y_{\text{center}} - y$).
- **Retrograde**: Reverse the temporal sequence ($x' = 1.0 - x$).
- **Metric Augmentation / Diminution**: Scale duration by 2x or 0.5x.
- **Modal Interchange**: Shift between parallel modes (e.g., D Natural Minor $\leftrightarrow$ D Dorian) by adjusting the 6th degree (Bb $\leftrightarrow$ B).
